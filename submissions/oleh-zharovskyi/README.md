# Oleh Zharovskyi: AI Vocabulary Learning App with SRS

Застосунок для вивчення англійських слів з інтервальним повторенням: ШІ (Google Gemini) додає український переклад і приклади речень, слова повторюються за розкладом +1 / +2 / +14 / +60 днів, потім потрапляють в архів.

Проєкт лежить в окремому репозиторії (за правилами завдання).

- **Код:** https://github.com/zharovskyi/words-tolearn (гілка `main`)
- **Сайт:** https://words-tolearn.vercel.app/
- **Звіт із доказами практик:** https://github.com/zharovskyi/words-tolearn/blob/main/REPORT.md
- **Відео-демо:** https://drive.google.com/file/d/1Puvg0CWQmW4MG3eq3qxUqGl4873K8lsz/view?usp=sharing

Докази в репозиторії проєкту: `AGENTS.md`, `openspec/`, `docs/trust_journal.md`, `docs/loop-log.md`, `docs/code-review.md`, `docs/reviewer-output.md`, `.claude/agents/reviewer.md`, команда `npm run verify` (95 тестів).
